# Security

Please report security issues for the BracketView marketing site and related services privately to **[support@bracketview.in](mailto:support@bracketview.in)**.

Do not open public GitHub issues that disclose exploits, secrets, or personal data. Use email (or a private channel) so details are not indexed or mirrored.

Privacy practices for the product and this website are described at:

**[https://bracketview.in/privacy](https://bracketview.in/privacy)**

Machine-readable contact: **[https://bracketview.in/.well-known/security.txt](https://bracketview.in/.well-known/security.txt)**

For the interactive app repository’s security policy, see that project’s `SECURITY.md`. This marketing repo (`bracketview-landing`) only covers `bracketview.in` content and tooling.
